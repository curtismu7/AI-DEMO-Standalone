3 · What this standardizes (and what each lab must change)

Becomes the one diagram look:

• Nodes: --box-dark|blue|grey|red fills, --on-box text, radius 8px, dark in both themes (§8 today — unchanged).

• Arrows: --muted stroke 1.5–2px; active = --accent 3.5px + numbered pill badge (surface fill, accent border); seen 55% opacity; future 30%.

• Canvas: --bg-lab background, 1px --border, radius 12px; toolbar and "now" strip use surface/surface-2.

• Legend: family chip pattern with fill dots; step list = details/summary, number in accent mono.

Convergence: pingone-lab (outline + stripe boxes) and any hand-rolled palette move to these fills; the diagram-studio box colors map 1:1 (red/dark/grey/blue/green→status-ok/amber→status-warn). CSS ships in the shared stylesheet so apps stop hand-rolling it.
