# Customer documents: Privilege SIEM through Cribl Stream to Elasticsearch

Generic, customer-ready (no hosts, tenants or credentials). Open the HTML files in a browser.

- `privilege-siem-cribl-setup-guide.html`: step-by-step setup with the tested Cribl and nginx configuration, verification and troubleshooting.
- `privilege-siem-cribl-test-report.html`: what was tested, the results, restrictions, prompt-logging findings and recommendations.

The configuration in the guide is derived from `shared/cribl-siem` (tested by `shared/cribl-siem/test/run-local.sh`). Update the guide there first if the configuration changes.
