Three steps: hold a static key, swap it for a platform-issued token, then watch the checks that bind the token to one workload.

    Demoingwhy Federated Identity exists: a static credential is a standing secret that outlives every mistake.

  3. 3

    Demoingclaim binding: a valid token from a workload outside the required claims still fails.

    Rejection becomes available once the token is federated.

    Token rejected

    The token is well-formed and correctly signed, but its claims name a different service account. Required claims pin sub to serviceaccount:analyst:portfolio-agent; this token says serviceaccount:other:scraper.

    An NHI does not authenticate anyone by itself: it needs the claim binding, a key behind it and a grant.
